
# 🎒 LPU Lost & Found

A simple Lost and Found website developed for Lovely Professional University (LPU) students.

This website helps students report lost belongings, report found items, and browse reports submitted by students.

## ✨ Features

- **Report an Item:** Submit details about lost or found belongings.
- **Item Details:** Enter item name, category, location, date, description and contact information.
- **Categories:** Electronics, Books, Clothing, Accessories and Other.
- **Browse Reports:** View submitted items in one place.
- **Filter Reports:** View all reports, lost items or found items.
- **Simple Design:** Easy-to-use interface for students.
- **Responsive Design:** Works on desktop and mobile screens.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Fill in the Lost or Found item form.
5. Click Submit Report.
6. Browse submitted reports and use the filter.

## ⚠️ Note

This is a frontend student project.

Reports are displayed temporarily using JavaScript and are not stored permanently. Refreshing the page clears submitted reports.

3. Open `index.html` using Live Server.

## ⚠️ Note

This is a student project developed for Lovely Professional University.

Reports are displayed temporarily using JavaScript. They are not stored permanently and will disappear when the page is refreshed.

The website currently uses frontend technologies only. A backend and database would be required to share reports between different users.
